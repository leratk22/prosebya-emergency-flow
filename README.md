# Просебя · аварийный флоу авторизации и записи · верстка

Статическая верстка по макетам в Paper
([файл](https://app.paper.design/file/01M4G9XECW85DD0WF65E9257BT)).
Токены в `assets/app.css` названы так же, как в Paper. Шапка, меню, футер и мобильное меню собираются в `assets/app.js`,
поэтому страницы работают только с включённым JS.

```bash
python3 -m http.server 4317
```

Открыть: http://localhost:4317/ — на `index.html` список всех экранов. Что изменилось относительно исходной системы — в [CHANGES.md](CHANGES.md).

## Страницы

Все экраны записи собраны на одном шаблоне «панель с шапкой и тонкой чертой» (`.panel`, степпер, мобильная и десктопная версии).

| Файл | Экран | Состояния (параметры в адресе) |
|---|---|---|
| `auth.html` | Вход по телефону | `?state=error` — ошибка номера |
| `sms.html` | Код из SMS: для любого номера верный код `0000` (как в исходной системе) | `?state=wrong` — неверный код |
| `loading.html` | Только лоадер | `?next=sessions.html` — переход после паузы |
| `sessions.html` | Мои записи: только предстоящие, «Перенести», «Отменить», копирование ссылки на встречу | `?state=empty` — записей нет, `?reset=1` — вернуть демо-записи |
| `specialties.html` | Запись, шаг 1 из 5 — специальность | `?state=loading`, `?state=error` |
| `specialists.html?spec=psychologist` | Шаг 2 из 5 — специалист | `?state=loading`, `?state=error` |
| `specialist.html?spec=psychologist&id=2` | Шаг 3 из 5 — календарь и время (список скроллится, один тап — дальше) | `?state=none`, `?state=unavailable` |
| `client.html` | Шаг 4 из 5 — «Проверьте ваши данные» (имя, фамилия, компания — вводятся вручную, телефон не спрашиваем: вход идёт по нему), ошибки под полями | `?state=errors` |
| `confirm.html` | Шаг 5 из 5 — проверка записи и согласие | `?state=unchecked` — кнопка недоступна |
| `booked.html` | «Вы записаны» | — |
| `reschedule.html?id=2` | Перенос, шаг 1 из 2 — новая дата и время | запись ближе 6 часов — возврат в «Мои записи» |
| `reschedule-confirm.html` | Перенос, шаг 2 из 2 — подтверждение | — |
| `rescheduled.html` | «Запись перенесена» | — |
| `cancel.html?id=2` | Отмена, причина необязательна | — |
| `error.html` | «Что-то пошло не так» (500) | — |
| `staff-specialist.html` | Календарь специалиста (кабинет сотрудников) | `?menu=1` — открытое меню, `?period=1` — список периода копирования |
| `staff-support.html` | Календарь поддержки | `?menu=1`, `?period=1` |
| `staff-admin.html` | Календарь админа (с переключателем «Запись по слотам») | `?menu=1`, `?period=1`, `?submenu=specialties` / `?submenu=users` — раскрытый раздел меню (содержимое подменю — заглушка) |
| `specialist-join.html` | Регистрация специалиста: фамилия, имя, почта, телефон, специальность (выпадающий список с поиском), логин, пароль. Проверки и тексты ошибок — из исходной системы; логины `admin` и `ivanova` считаются занятыми; после успеха — календарь специалиста | `?state=errors`, `?state=open`, `?demo=many` |
| `staff-login.html` | Вход сотрудника: логин и пароль обязательны, неверные данные — красная плашка сверху; демо-вход: логин `specialist`, `support` или `admin`, пароль `demo1234` (ведёт в календарь роли); «выход» из календарей приходит сюда | `?state=error`, `?state=required`, `?state=logout`, `?captcha=1` — проверка «я не робот», `?state=captcha` |
| `staff-recovery.html` | Напоминание пароля: логин и почта; «найденные» логины демо — `specialist`, `support`, `admin`; успех — состояние «Проверьте почту» с иллюстрацией | `?state=error`, `?state=sent`, `?captcha=1` |
| `staff-reset.html` | Новый пароль по ссылке из письма: от 7 символов, пароли совпадают; без рабочего токена — «Ссылка недействительна» | `?token=demo` — рабочая ссылка, `?state=errors`, `?state=done` |

Порядок флоу записи: телефон → код → «Мои записи» → специальность → специалист → дата и время → данные → проверка → «Вы записаны».
«Сегодня» в макете — пятница 9 октября 2026, 14:07; перенос и отмена доступны не позднее чем за 6 часов до начала.
Записи хранятся в `localStorage` (запись, перенос и отмена меняют список).

Кабинет сотрудников (`staff-*.html`) собран отдельно от клиентского флоу: свои стили `assets/staff.css` и скрипт `assets/staff.js`, шапка и меню лежат прямо в разметке.
До 1024 px вместо верхней навигации — бургер и мобильное меню (пункты роли, имя пользователя и «Выйти» внизу), на десктопе — навигация в шапке и меню пользователя.
Данные в сетке демонстрационные: клик по ячейке открывает/закрывает слот, «Скопировать неделю на» переносит открытые слоты на 1–2 следующие недели, «Очистить неделю» убирает их; создание сессии и разделы «Записи», «Клиенты» и т.д. не сверстаны.

Плашки ошибок и уведомлений (`.toast`, `.toast--info`, `.toast--success`) парят над шапкой: на телефоне по ширине экрана, на десктопе по ширине белой карточки (788 px). `showToast(текст, "info" | "success")` в `assets/app.js`.

## Допущения

- Список специалистов один на все специальности (в макете показан только «Психолог»).
- Время приёма — каждые 30 минут с 06:00 до 23:30, на день показывается часть слотов; список времени скроллится.
- Слоты генерируются в `app.js` по тем же правилам, что в макете: сегодня только вечер и ночь, дальше больше.
- Шрифт SemiBold подключён как `.ttf`: woff2 в проекте для него нет.
