# Просебя · аварийный флоу авторизации и записи · верстка

Статическая верстка по макетам в Paper
([файл](https://app.paper.design/file/01M4G9XECW85DD0WF65E9257BT)).
Токены в `assets/app.css` названы так же, как в Paper. Шапка, меню, футер и мобильное меню собираются в `assets/app.js`,
поэтому страницы работают только с включённым JS.

```bash
python3 -m http.server 4317
```

Открыть: http://localhost:4317/ — на `index.html` список всех экранов.

## Страницы

| Файл | Экран | Состояния (параметры в адресе) |
|---|---|---|
| `auth.html` | Вход по телефону | `?state=error` — ошибка номера |
| `sms.html` | Код из СМС (верный код в макете — `0`, ввод и Enter; 4 цифры проверяются сами) | `?state=wrong` — неверный код, красный тост |
| `loading.html` | Только лоадер | `?next=client.html` — переход после паузы |
| `client.html` | Данные клиента | ошибки «Укажите имя / название компании» на blur, кнопка недоступна до заполнения и согласия, системный календарь по иконке |
| `specialties.html` | Список специальностей | `?state=loading` — скелетон, `?state=error` — 500 |
| `specialists.html?spec=psychologist` | Специалисты специальности | `?state=loading`, `?state=error` |
| `specialist.html?id=2` | Дата и время (14 дней, Утро/День/Вечер/Ночь) | `?state=none` — нет мест, `?state=unavailable` — время недоступно |
| `confirm.html` | Подтверждение записи | `?state=unchecked` — чекбокс снят, кнопка недоступна |
| `session.html` | Запланированная сессия | — |
| `sessions.html` | Мои сессии клиента | последняя сессия отменена: плашка «Отменена», без стрелки |
| `error.html` | «Что-то пошло не так» (500) | — |
| `specialist-sessions.html` | Кабинет специалиста: сессии по дням | `?reset=1` и ссылка внизу — сбросить отметки |

Порядок флоу: телефон → код → данные → специальности → специалисты → время → подтверждение → сессия.

## Кабинет специалиста

Меню нет, имя специалиста и выход — в шапке. Сессии сгруппированы по дням, у каждого клиента две кнопки
«Состоялась» / «Не состоялась» (с иконками, без привязки к полу специалиста). После нажатия кнопки заменяются статусом («Вы отметили: сессия состоялась / не состоялась»),
отметка необратима. Отметить можно только сессию, которая уже началась; будущие кнопки недоступны.
В макете «сейчас» — пятница 9 октября 14:07. Отметки хранятся в `localStorage`.

## Допущения

- Список специалистов один на все специальности (в макете показан только «Психолог»).
- Слоты генерируются в `app.js` по тем же правилам, что в макете: сегодня только вечер и ночь, дальше больше.
- Шрифт SemiBold подключён как `.ttf`: woff2 в проекте для него нет.
